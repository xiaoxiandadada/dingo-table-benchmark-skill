# 评分与结果解读

TEDS = 100 × (1 − D_text / max(N_pred, N_gold))。
S-TEDS = 100 × (1 − D_structure / max(N_pred, N_gold))。

两者越高越好；数据集取单表平均。90 分不代表 90% 整表完全正确。节点数采用评分实现定义，不等于单元格数。

树编辑代价：增删节点为 1；标签或 rowspan/colspan 不同的替换代价为 1；结构相同的单元格内容用标准化字符/内容序列编辑距离。S-TEDS 将格内内容置空后只比较结构；TEDS-S 与 S-TEDS 属同类称法，仍需核验各论文代码。空树和非法 HTML 的行为由协议明确处理。

使用官方实现并固定代码哈希。至少验证：同表满分；只改文字使 TEDS 降低而 S-TEDS 不变；改变合并跨度使 S-TEDS 降低；截断计零且不退出分母。

历史协议：提取所有完整 table，按原顺序连接分段；th→td；剥离 thead/tbody 与展示标签、压缩空白、br→空格；保留单元格文字与跨度。不人工改预测。分段连接和格式忽略是项目协议，不声称原生官方评测必然相同。

统一分母是已冻结金标的整批样本；失败、截断和无完整表格计 0。pending 尚未执行必须披露，不能称最终全量分数。结构分组允许交叠，每组写 n；不能由整体低分推断具体错误。比较必须绑定图像哈希、金标版本及运行配置。

## 本轮结果的含义

结果快照保留六模型 v2/4096 基线；TRivia 在该 30 张困难集上两指标最高，MinerU 次之。UniTable 的文字与结构分数差距大，说明结构分数较高不等于内容可靠。DeepSeek 的速度数据含 API 网络时间且有一张截断；其他模型计时口径不同，不能据此作严格吞吐排名。

180 份输出做过 Astra 辅助逐格检查及助手抽查，119 份含高置信问题标记、61 份未标高置信错误。这不是独立人工双审，不能据此证明剩余输出完全正确；复核还暴露参考金标疑点，历史 v2 快照不应冒称已消除所有疑点的最终真值。
